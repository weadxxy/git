微光之境的 Windows 桌面版，可以安装到电脑，双击桌面快捷方式直接游玩。

下载下方的 `Lumenfall-1.1.0-Windows-x64-Setup.exe`，双击安装，完成后打开「微光之境 Lumenfall」。适用于 Windows 10/11 64 位，游戏可离线运行，无需浏览器或 Node.js。

操作：A/D 移动，空格二段跳，J 挥剑，K 冲刺，Esc 暂停，F11 全屏，Ctrl+Q 退出。

安装包尚未配置代码签名证书，Windows 可能显示发布者未知。请核对本仓库及附件 SHA256SUMS.txt 中的校验值；无需关闭系统防护。

包含完整像素森林关卡、光影粒子、合成音效、12 枚可收集碎片、路灯复活点和星门通关。进度保留在本次运行中，关闭游戏会重新开始。
