# 微光之境 · Lumenfall

一个可直接在浏览器中游玩的 2D 横版像素冒险游戏。使用原生 Canvas 2D、JavaScript 和 Web Audio，无需安装第三方运行依赖，也不依赖外部图片、字体或音频服务。

## 启动

需要 Node.js 18 或更高版本：

```sh
cd /workspace/git
npm run dev
```

默认监听端口 `3000`。可通过 `PORT=8080 npm start` 更换端口。页面由 `index.html`、`style.css`、`game.js` 构成，也可部署到任意静态网站托管服务。

## 玩法

- **A / D 或左右方向键**：移动。
- **空格 / W / 上方向键**：跳跃；空中可再跳一次。
- **J**：挥剑，暗影需要两次攻击，也可以从上方踩踏消灭。
- **K / Shift**：短暂冲刺，穿过危险；有冷却时间。
- **Esc**：暂停或恢复。切换窗口会自动暂停。
- 触屏设备显示移动、跳跃、挥剑和冲刺按钮，建议横屏游玩。

关卡中共有 **12 枚光之碎片**，收集至少 **8 枚**，抵达最右侧星门即可通关。两个路灯会恢复生命并记录本局复活位置。死亡后可保留碎片，从最近的路灯继续；重新出发会重置本局。进度仅在当前页面内保留，刷新页面会重新开始。

声音默认关闭；点击右上角扬声器可开启合成环境音乐及交互音效。支持全屏与减少动态效果偏好。

## 验证

```sh
npm run check
```

浏览器集成测试使用 Python Playwright 和 Chromium。在已安装这些测试工具的环境中，先启动服务器，再执行：

```sh
python tests/browser_test.py
```

测试以真实键盘和触屏事件运行游戏，不修改游戏状态。`?test=1` 仅提供只读状态用于断言；普通页面不暴露该接口。

## 文件

- `game.js`：关卡、物理碰撞、战斗、程序化像素绘制、光效粒子和音频。
- `style.css`：响应式界面、触屏控件、暂停及通关弹窗。
- `server.mjs`：无第三方依赖的本地静态开发服务器。

这是完整的单关卡小游戏；角色、关卡和美术均为程序绘制，可以继续扩展关卡或替换为精灵图。
